### 3.2 可自動化的測試寫法（vitest，`@vue/test-utils`＋`happy-dom`，專案現有組合）

核心是**給每個 V2Num 一個固定的鉤子**，測試不依賴卡片文字、class：

```ts
// tests/helpers/v2Num.ts（草案）
export async function assertEveryNumberDrills(w: VueWrapper, expect: Vitest['expect']) {
  const nums = w.findAll('[data-v2num]')
  expect(nums.length).toBeGreaterThan(0)
  for (const n of nums) {
    const st = n.attributes('data-state')               // value | zero | nodata | error | denied
    const to = n.attributes('data-to')                  // 下鑽路由，JSON 或字串
    if (st === 'denied') {
      expect(n.find('a').exists()).toBe(false)
      expect(n.attributes('aria-disabled')).toBe('true')
      expect(n.text()).toMatch(/沒有權限/)
      continue
    }
    if (st === 'error') { expect(n.find('button.retry').exists()).toBe(true); continue }
    expect(to, `數字「${n.text()}」沒有下鑽目標`).toBeTruthy()      // value / zero / nodata 都要有
    // 0 一定要有連結（A1 的核心）
    if (st === 'zero') expect(n.find('a').exists()).toBe(true)
  }
}
```

測試案例清單（每頁一檔，檔名沿用現有 `v2<Page>.spec.ts` 風格；mock `useApi().apiFetch` 的固定資料，不碰真實 API）：

1. **五種狀態矩陣**：用 `it.each([['value',{n:5}],['zero',{n:0,status:'ok'}],['nodata',{n:null,status:'uncollected'}],['error',{status:'error'}],['denied',403]])` 掛載同一頁，斷言 `data-state` 與外觀（文字、`data-to`）。這同時取代現有的 `codexChangesSourceStates`／`codexChangesMissingSource` 兩支字串斷言（保留舊測試到新測試過了再刪）。
2. **每個數字都有反應**：`assertEveryNumberDrills(wrapper)`＋對每個 `value／zero` 的 `data-to` 以路由解析器驗證：目標路由存在（`pages/v2/*.vue` 對得到）、query 的鍵被目標頁讀取（沿用 `test_v2_deeplinks_bidirectional.py` 的「落點讀日期與分類」寫法）。
3. **證據列欄位**：掛載明細頁，`wrapper.find('[data-testid="v2-evidence"]')` 內依序出現 來源名＋時間／條件標籤／分母／被排除（若有）／共 N 筆；改 `route.query` 篩選後 N 變、與表格 `total` 同步。
4. **排序與匯出**：`nodata` 排最後；匯出 CSV 內 `nodata` 為空白＋原因欄，非 `0`。
5. **選擇器穩定**：既有測試用 `.kc`、`.tile`（見 `01` §五）；遷移期新舊鉤子並存，舊測試改完再拿掉。

### 3.4 靜態守門（pytest，讀原始碼）

沿用 `test_v2_three_layers.py` 的「名單只能縮小」寫法：

- 掃 `pages/v2`、`components/v2` 的條件式 `link:`（`? … : null`／`&&`），**每檔上限＝目前基線**（01 文件的 99 處，逐檔），**只能減不能增**；遷移一頁就調降該頁的上限。
- 掃 `catch` 後面只有空白或註解者（FE 目前 23 處）不得新增（與既有 `test_no_silent_catch.py` 並存，**未驗證**兩者白名單是否重疊）。
- `<V2Table` 必須有 `empty=` 且字數≥8（附下一步）——第 2 批再開，第 0／1 批不擋。
