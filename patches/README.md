# Patches

依日期分資料夾，每天一個。**要套用就進最新日期的資料夾，取檔名時間最大的那一包。**

```
patches/
  20260729/
    patch_20260729_1600.tar.gz     ← 這天最新的
    patch_20260729_1600.sha256
    patch_20260729_1533.tar.gz
    ...
```

## 只要套最新那一包

每包都含「從公司主機安裝的版本到最新」的**全部**改動，不是逐版增量。
所以不必依序套用、也不用擔心漏掉中間哪一包。

## 怎麼套

把 `.tar.gz` 傳到目標主機的 `/tmp/`，然後：

```bash
cd /tmp && tar xzf patch_YYYYMMDD_HHMM.tar.gz && cd patch_YYYYMMDD_HHMM && sudo bash patch.sh
```

`patch.sh` 會自己做完：備份舊檔 → 換檔 → 修換行 → 讀出這台的安裝設定 → 確認連接埠 → 重啟並驗證。
開頭會印「目前版本 → 這包版本」，結尾會講升到哪一版，看那兩行就知道有沒有成功。

## 檢查檔案有沒有傳壞

```bash
sha256sum -c patch_YYYYMMDD_HHMM.sha256
```

## 出事了

`patch.sh` 失敗時會印出備份路徑和一行還原指令，照著跑就回到套用前的狀態。
腳本是冪等的，修好之後直接重跑同一包即可。
